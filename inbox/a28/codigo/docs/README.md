# Documentacion CU28

`docs/` contiene exclusivamente el contrato tecnico estable de CU28. Los
resultados generados, metricas, auditorias, EDA y evidencias viven en
`../reports/` o en los artefactos oficiales de `../models/metrics/`.

La ruta reproducible oficial es `mixed_context`. `platform_run` es solo una
utilidad secundaria de inferencia batch/offline para CSV.
