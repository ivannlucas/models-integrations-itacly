# ETL Pipeline

| Fase | Input | Transformacion | Output | Comando | Evidencia |
| --- | --- | --- | --- | --- | --- |
| `build_external_long` | `data/raw/external/INE_CPI/*`, `MAPA_SLAUGHTER_MAPA/*`, `MAPA_PRICES_OM/*` | Ingesta controlada de fuentes activas/traced, normalizacion a formato largo y cache intermedio | `data/processed/external/context/external_long.csv` | `python -m src.main etl --mixed-context` | `data/interim/external/build_external_long__mixed_context.json` |
| `build_context_weekly` | `external_long.csv`, caches intermedios mensuales/semanales | Resampling semanal, indices base 100 y limitaciones proxy | `context_weekly_for_simulation.csv`, `context_proxy_limitations.json` | `python -m src.main etl --mixed-context` | `data/interim/external/build_context_weekly__mixed_context.json` |
| `build_synthetic_plant_layer` | `context_weekly_for_simulation.csv`, `config/manufacturing_profiles.yaml`, `config/config.yaml` | Construccion de capa operativa sintetica declarada | `synthetic_plant_layer__mixed_context.csv`, `synthetic_plant_metadata__mixed_context.json` | `python -m src.main etl --mixed-context` | `data/interim/synthetic/build_synthetic_plant_layer__mixed_context.json` |
| `build_modeling_dataset` | `synthetic_plant_layer__mixed_context.csv` | Feature engineering, aliases oficiales, columnas target y export del dataset modelable | `feature_engineering_modeling__mixed_context.csv`, `modeling_metadata__mixed_context.json` | `python -m src.main etl --mixed-context` o `python -m src.main feature_engineering --mixed-context` | `data/interim/synthetic/build_modeling_dataset__mixed_context.json` |
| `make_splits` | `feature_engineering_modeling__mixed_context.csv` | Splits cronologicos train/validation/test sin usar test para seleccion | `data/splits/baseline/default__mixed_context/*` | `python -m src.main make_splits --mixed-context` | `split_metadata.json` |

Notas:

- La ruta oficial mixed_context usa fuentes externas/proxy mas una capa sintetica de planta declarada.
- No se reintroducen notebooks como paso operativo.
